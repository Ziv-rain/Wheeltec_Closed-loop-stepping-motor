系统链路

MaixCam→UART2→proto_rx→VisionEstimator→PID_UpdateWithDerivative→CL_SetTargetAngle→CL_Process→步进电机

🔄 调参流程

准备

1. 硬件上电（12V + USB-C × 2）
2. 等待自动归零完成（PWM ≈ 143°，串口打印启动信息）
3. 球放摆杆中间（约 0cm 位置）
4. 确认 MaixCam 工作（镜头对准摆杆，能看到球）
1

关 D 关 I，找 P 临界值

M 0          ← KD = 0
I 0          ← KI = 0
V            ← 启动 PID

从小到大试 KP，每次 S 观察球的行为：

KP现象判断
0.3球慢慢漂走，回不来太小
0.6球能回来，但很慢还不够
0.9球冲过头弹回去接近了
1.2球来回振荡，幅度不衰减临界 KP
1.5振荡更剧烈超标了

记录：临界 KP = ___，振荡周期 Tu = ___ 秒（看 S 输出 ball 值摆动一次的时间）

2

回退 KP，加 KD 阻尼

J 0.7        ← 临界 KP × 0.6（例如 1.2 × 0.6）
M 0.1        ← 从小 KD 开始
现象操作
球过冲超过目标M +0.1 加大刹车
球回来太慢、反应迟钝M -0.05 减小刹车
球到中心附近轻微摆动后稳住✅ 这组 KP/KD 可用

经验公式：KD ≈ KP × Tu × 0.3 （Tu=0.5s 时 KD ≈ 0.18）

3

微调 KP + KD 组合

球的行为问题操作
小幅持续摆动（高频）KD 不够M +0.05
大幅缓慢摆动（低频）KP 太大J -0.2
球偏一边回不到 0cmKP 不够J +0.1
球反应迟钝KP+KD 都大J -0.2 M -0.05

目标：球放中间松手后，2-3 秒内稳定在 ±3mm 以内。

4

加积分（按需）

如果 PD 调好后球停在离 0cm 差 >0.3cm 的位置：

I 0.02       ← 先加很小
现象操作
误差慢慢缩小，球到 0cm✅ KI 合适
缩小太慢I 0.05
出现小幅振荡I 0 放弃积分

能不用就不用。PD 调好通常不需要 KI。

5

跨位置验证

N 5          ← 目标移到 +5cm
N 0          ← 回到中心
N -3         ← 测试负方向
现象操作
过冲超过目标 0.5cmM +0.1
到不了目标（差 >0.3cm）J +0.2 或 I 0.03
来回振荡几次才稳M +0.05
三个位置都顺利到位✅ 调参完成

🔧 典型问题

球完全不动 / 电机不转

S 检查：

  • PWM≈143 且 act=0 → 归零没完成，等
  • valid=0 → MaixCam 没发数据，检查 UART2 接线和供电
  • ball 值始终不变 → 检查摄像头是否对准、光照是否充足

球一启动就飞出去

X 立刻急停 → J 0.3 重新开始

  • KP 太大
  • 方向反了 → 检查 AXIS_X_POSITIVE_DIR_LEVEL
  • 速度滤波太小 → 改 VIS_VELOCITY_FILTER_ALPHA = 0.85

球在目标附近高频抖动

  • KD 不够 → M +0.1
  • 视觉噪声大 → VIS_VELOCITY_FILTER_ALPHA = 0.85，VIS_POSITION_DEADBAND_CM = 0.2

球稳定但位置有偏差

  • 平台物理不平 → T 0.5 或 T -0.5
  • 有稳态误差 → I 0.03

上电→等归零→球放中间→V→M 0→I 0→J 0.3~1.5 找临界→回退+加D→N 5/N 0/N -3 验证

KP 管力度 · KD 管刹车 · KI 管精准
先 KP+KD 调到稳，够用就不加 KI
