# 七段开环钢球运动台架调参

本版本实现 `0 cm → +5 cm → -5 cm` 七段开环运动，默认参数来自
`open_loop_ball_simulation_package.zip`，持续时间已按固件 `5 ms` 周期取整。

## 烧录前

1. 使用 CCS/SysConfig 重新生成并完整编译工程；
2. 确认 `Hardware/demo_config.h` 中 `DEMO_SELECT` 为 `7`；
3. 准备硬件急停和机械限位，首次测试先不放钢球；
4. UART0 使用 `115200-8-N-1`，每条普通命令末尾发送回车。

## 默认七段参数

| 段 | 作用 | 电机角 | 时间 |
| ---: | --- | ---: | ---: |
固件在自动回水平后把当前位置设为 `0°`，因此下表是相对于实物水平零点的闭环目标角；
压缩包中的四连杆绝对机械角已减去理论水平角 `0.2063°`。

| 段 | 作用 | 固件目标角 | 时间 |
| ---: | --- | ---: | ---: |
| 1 | 初始水平 | 0° | 200 ms |
| 2 | 向 +5 cm 加速 | -24.2063° | 365 ms |
| 3 | 向 +5 cm 制动 | +19.7937° | 335 ms |
| 4 | +5 cm 静置 | 0° | 550 ms |
| 5 | 向 -5 cm 加速 | +34.7937° | 405 ms |
| 6 | 向 -5 cm 制动 | -20.2063° | 430 ms |
| 7 | -5 cm 静置 | 0° | 800 ms |

## 串口运行顺序

上电后先查询：

```text
S
```

只有看到 `Home=READY` 才能运行。首次无球检查方向：

```text
D-5
D0
D5
D0
```

放球后只运行第一航段：

```text
K1
```

确认不会接近 `+9 cm` 后，可从当前 `+5 cm` 位置只运行第二航段：

```text
K2
```

完整流程必须从中心 `0 cm` 开始：

```text
K
```

运动中随时发送单字符 `X`，无需回车，会锁存急停；急停后必须重新上电。

## 调参命令

查看当前七段：

```text
V
```

例如把第二段改成 `355 ms`，第三段改成 `345 ms`：

```text
E2355
E3345
```

例如把第二段相对水平角度改成 `-22°`：

```text
Q2-22
```

时间必须是 `5 ms` 的整数倍；角度限制固定为 `-30°～+45°`。序列运行时拒绝修改参数。

调参原则：

- 到不了 `+5 cm`：第二段每次增加 `5～10 ms`，或第三段减少 `5 ms`；
- 超过 `+5 cm`：第二段减少，或第三段增加；
- 到不了 `-5 cm`：第五段增加，或第六段减少；
- 超过 `-5 cm`：第五段减少，或第六段增加；
- 一次只修改一个参数，并记录 `V` 输出和实际落点。

## PC 仿真

无需第三方 Python 库：

```powershell
python simulation/open_loop_ball/open_loop_ball_simulation.py
```

修改角度和时长后运行：

```powershell
python simulation/open_loop_ball/open_loop_ball_simulation.py `
  --angles 0.2063 -24 20 0.2063 35 -20 0.2063 `
  --times-ms 200 365 335 550 405 430 800
```

输出位于 `simulation/open_loop_ball/output/`。仿真是开环初值，不代表实物无需调参。
