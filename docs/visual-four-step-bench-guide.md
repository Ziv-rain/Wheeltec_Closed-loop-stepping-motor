# DEMO8 视觉辅助往返与稳定调试说明

源分支 `四步结合视觉` 使用 `DEMO_SELECT=8`，目标运动为：

```text
0 cm -> +5 cm -> -5 cm -> 在 -5 cm 附近稳定
```

最新控制只有第一阶段使用固定角度。有有效视觉数据时：

1. 第一阶段到达约 `+4.7 cm` 后提前转入回程；
2. 位置外环根据剩余距离生成 `-5～+5 cm/s` 的目标速度；
3. 速度内环连续调整角度，速度过快时自动反向制动；
4. 进入目标 ±0.5 cm且低速后，切换到带小积分和静摩擦补偿的保持控制。

回程或捕获期间视觉超过 100 ms无效时立即退出并回水平，不再盲目执行
固定角度。`E2/E3` 分别作为回程和捕获的安全超时。

## 默认参数

```text
Q1=-10°  E1=600 ms    0 -> +5 cm
Q2= +4°  E2=8000 ms   回程闭环最大驱动角/安全超时
Q3= -5°  E3=10000 ms  回程闭环最大制动角/捕获安全超时
Q4=  0°  E4=5 ms      稳定后交给持续视觉保持

目标位置 N=-5 cm
保持位置增益 J=0.50 deg/cm
保持速度阻尼 M=0.40 deg/(cm/s)
保持积分增益 I=0.08
正常保持输出限制 -1.5°..+1.5°
回程最大速度 5 cm/s
```

保持控制仅在目标附近使用有限积分，并在小球基本静止但误差超过 0.25 cm时
加入 0.45° 静摩擦补偿。预计未来 0.2 秒会越过目标负方向 0.75 cm时，
控制器仍会使用 `-5°` 强制制动。

## 串口命令

UART0：`115200-8-N-1`。

```text
S       查看视觉有效性、目标、位置、滤波速度、输出和序列阶段
K       运行往返序列，结束后自动进入视觉稳定
V       手动启动视觉稳定
W       停止视觉稳定并回水平补偿
U       切换序列结束后是否自动启动视觉
N-5     设置视觉目标为 -5 cm
J0.50   设置保持位置增益
M0.40   设置保持速度阻尼
I0.08   设置保持积分增益
Q1-10   设置第1阶段角度
Q2+4    设置回程闭环最大驱动角
Q3-5    设置回程闭环最大制动角
E1600   设置第1阶段最长时间，必须是5 ms整数倍
X       立即锁存急停，恢复必须重新上电
```

`U` 是切换命令。测试前使用 `S` 确认 `auto=1`、`sp=-5.00`、
`valid=1`、`fault=0`。`S` 新增：

- `vel`：滤波后小球速度，负值表示向 -5 cm 方向运动；
- `vref`：位置外环生成的目标速度，接近 -5 cm时应逐渐趋近 0；
- `seq`：0 表示序列未运行，1..4 表示当前阶段。
- `stable`：位置在目标 ±0.5 cm且低速连续保持 500 ms 后显示 1。

## 首次上台步骤

1. 不放球确认自动回零完成，PWM 在机械安全范围内。
2. 准备硬件断电开关，先用小角度验证正负方向与本说明一致。
3. 放球后使用 `S`，确认 `ball` 和 `vel` 持续更新。
4. 执行 `N-5`，确认 `sp=-5.00`。
5. 首次执行 `K` 时随时准备发送 `X` 或断电。
6. 记录小球首次进入 -5 cm 时的 `ball/vel/vref/out/seq/stable`。

## 调参顺序

- 回程速度过高：减小 `Q2`，不要缩短 `E2`；`E2` 现在是安全超时。
- 制动能力不足：增大 `Q3` 的绝对值；`E3` 现在是捕获安全超时。
- 到点后低频往返：降低 `J`。
- 到点速度仍偏大：适当提高 `M`。
- 停在目标外且 `vel` 接近零：先校准水平 `T`，再小幅提高 `I`。

本版控制目标为：最低位置不得小于 `-6.0 cm`；最终
`-5.5 cm <= ball <= -4.5 cm` 且 `|vel| <= 0.5 cm/s`，
连续保持至少 0.5 秒，此时 `S` 应显示 `stable=1`。

建议连续运行至少 10 次，记录最低位置和最终位置，不能只用单次结果判断。

## 安全行为与限制

- 视觉数据超过 100 ms 无效时退出视觉闭环并回水平微调角；
- 球位置越过 `±9 cm`、PWM 丢失或触及硬限位时停止当前控制；
- 视觉速度只在新相机帧到达时更新，使用真实帧间隔，不再把缓存位置
  每 5 ms 重复微分；
- 完整 CCS/SysConfig 构建、烧录和实物验收仍必须在对应 SDK 和硬件上完成。
