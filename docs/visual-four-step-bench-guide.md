# DEMO8 视觉辅助往返与稳定调试说明

源分支 `四步结合视觉` 使用 `DEMO_SELECT=8`，目标运动为：

```text
0 cm -> +5 cm -> -5 cm -> 在 -5 cm 附近稳定
```

最新控制不再把四步全部按时间盲目执行。有有效视觉数据时：

1. 第一阶段到达约 `+4.7 cm` 后提前转入回程；
2. 第二阶段根据球速、剩余距离和估算制动距离提前刹车；
3. 第三阶段反向倾斜消除回程速度；
4. 第四阶段回水平，随后自动进入小角度视觉 PD 保持。

视觉暂时不可用时，每阶段仍受 `E1..E4` 时间上限约束，不会卡死。

## 默认参数

```text
Q1=-10°  E1=600 ms    0 -> +5 cm
Q2= +6°  E2=600 ms    +5 -> -5 cm 回程
Q3= -3°  E3=300 ms    反向制动
Q4=  0°  E4=150 ms    回水平并等待接管

目标位置 N=-5 cm
位置增益 J=0.8 deg/cm
速度增益 M=0.25 deg/(cm/s)
积分增益 I=0
视觉输出限制 -6°..+6°
```

这些是保守的首次上台参数，必须根据机构摩擦、相机帧率和电机方向实测微调。

## 串口命令

UART0：`115200-8-N-1`。

```text
S       查看视觉有效性、目标、位置、滤波速度、输出和序列阶段
K       运行往返序列，结束后自动进入视觉稳定
V       手动启动视觉稳定
W       停止视觉稳定并回水平补偿
U       切换序列结束后是否自动启动视觉
N-5     设置视觉目标为 -5 cm
J0.8    设置位置增益
M0.25   设置滤波速度增益
I0      关闭积分
Q1-10   设置第1阶段角度
E1600   设置第1阶段最长时间，必须是5 ms整数倍
X       立即锁存急停，恢复必须重新上电
```

`U` 是切换命令。测试前使用 `S` 确认 `auto=1`、`sp=-5.00`、
`valid=1`、`fault=0`。`S` 新增：

- `vel`：滤波后小球速度，负值表示向 -5 cm 方向运动；
- `seq`：0 表示序列未运行，1..4 表示当前阶段。

## 首次上台步骤

1. 不放球确认自动回零完成，PWM 在机械安全范围内。
2. 准备硬件断电开关，先用小角度验证正负方向与本说明一致。
3. 放球后使用 `S`，确认 `ball` 和 `vel` 持续更新。
4. 执行 `N-5`，确认 `sp=-5.00`。
5. 首次执行 `K` 时随时准备发送 `X` 或断电。
6. 记录小球首次进入 -5 cm 时的 `ball`、`vel`、`out`、`seq`。

## 调参顺序

- 仍越过 -5.5 cm：减小 `Q2` 或 `E2`，增大 `Q3` 的绝对值或 `E3`。
- 刹车过早、停在 -4 cm右侧：略增 `Q2/E2`，或减小 `Q3/E3`。
- 到点后低频往返：降低 `J`。
- 速度噪声导致输出抖动：降低 `M`；不要直接提高 `J`。
- 存在稳定静差：先校准水平 `T`，最后才尝试很小的 `I`。

验收条件建议为：`-5.5 cm <= ball <= -4.5 cm` 且
`|vel| <= 1 cm/s`，连续保持至少 0.5 秒。

## 安全行为与限制

- 视觉数据超过 200 ms 无效时退出视觉闭环并回水平微调角；
- 球位置越过 `±9 cm`、PWM 丢失或触及硬限位时停止当前控制；
- 视觉速度只在新相机帧到达时更新，使用真实帧间隔，不再把缓存位置
  每 5 ms 重复微分；
- 完整 CCS/SysConfig 构建、烧录和实物验收仍必须在对应 SDK 和硬件上完成。
