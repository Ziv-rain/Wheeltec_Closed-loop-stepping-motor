# DEMO8 四步序列与视觉精调台架说明

源支线 `四步结合视觉` 使用 `DEMO_SELECT=8`：先运行四步开环序列，再自动进入视觉 PID。

## 串口命令

UART0：`115200-8-N-1`。

```text
S       查看回零、视觉有效性、故障和电机状态
K       运行四步序列，结束后自动进入视觉精调
V       手动启动视觉精调
W       停止视觉精调并回到水平补偿
N0      设置视觉目标为 0 cm，可设范围 -9～+9 cm
Q1-10   设置第1步角度，允许范围 -30°～+45°
E1600   设置第1步时间，必须为5 ms整数倍
X       无需回车，立即锁存急停；恢复必须重新上电
```

上电后先发送 `S`。只有回零完成后，`K` 和 `V` 才会执行。`Z` 不再允许手动改写零点。

## 首次测试

1. 不放钢球，确认自动回零完成且 `S` 显示 PWM 在机械范围内；
2. 使用较小的 `Q1/Q2` 角度和短时间验证电机方向；
3. 放球后确认 UART2 视觉数据持续更新；
4. 先手动执行 `V`，遮挡摄像头，确认电机回到水平而不是保持倾角；
5. 再执行 `K`，过程中保持硬件急停可用；
6. 任何异常立即发送 `X` 或断电。

## 重要行为

- 视觉丢失、球位置越过 `±9 cm`、PWM 丢失或触及硬限位时，视觉 PID 停止；
- 视觉丢失后目标角回到水平微调值，不会保持丢失前的倾斜角；
- PID 输出限制为 `-30°～+45°`；
- 四步角度和时间在序列运行期间不能修改；
- 四步持续时间按 5 ms 控制周期执行，不再提前一个周期切段。

本分支仍需在实际 CCS/MSPM0 SDK 环境完成全量编译和实物台架验证。
