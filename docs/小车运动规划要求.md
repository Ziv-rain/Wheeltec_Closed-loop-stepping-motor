# 小车运动规划要求(给主控端)

> 目的: 让小球在车上"稳如磐石"——通过控制小车的加速度,使加速度前馈能 100% 抵消惯性扰动。
> 日期: 2026-08-01 | 分支: feat/accel-fusion

---

## 一、一句话结论

**小车加速度 ≤ 2 m/s² 且缓慢渐变(不要突跳),前馈就能让球几乎不动。**

---

## 二、为什么是 2 m/s²?

### 前馈的物理模型

```
小车加速度 ax → 球受到"虚拟惯性力" -ax
前馈摆杆倾角:  θ_ff = atan2(-gain·ax, g) × 57.3°

球感受到的净加速度 = 重力分量 - 惯性力
  = Kθ·(θ_实际 - θ_ff)
```

当 `θ_实际 = θ_ff` 时,球净加速度 = 0 → **球完全不动**。

### 补偿上限

当前 MSPM0 前馈限幅 **±12°**:

```
完全抵消 ax 所需倾角 = tan⁻¹(ax / 9.81)
  12° 对应 ax = tan(12°) × 9.81 ≈ 2.1 m/s²

结论:
  |ax| ≤ 2.0 m/s²  → 前馈 100% 抵消,球不动    ✅ 理想区
  |ax| > 2.1 m/s²  → 前馈饱和,球开始滑动       ⚠️ 避免
```

---

## 三、加速度变化率(jerk)同样重要

前馈信号有低通滤波(EMA,响应约 100ms)。加速度**突变**时:

```
ax:  0 ──────→ 2.0 m/s²  (瞬间跳变)
ff:  0 ──滞后──→ 12°      (100ms 后才跟上)
     ↑
     这 100ms 球在"裸奔",被惯性甩 ← 不想要

ax:  0 ──1s渐变──→ 2.0 m/s²  (平滑爬升)
ff:  0 ──跟随────→ 12°        (每步都跟得上) ✓
```

**加速度变化率建议 ≤ 2 m/s²/s**(即 1 秒内加速度最多变化 2 m/s²)。

---

## 四、量化要求汇总

| 指标 | 建议值 | 硬上限 | 说明 |
|------|--------|--------|------|
| 最大加速度 | **≤ 2.0 m/s²** | 2.5 m/s² | 前馈完全补偿范围 |
| 加速度变化率(jerk) | **≤ 2 m/s²/s** | 3 m/s²/s | 前馈 EMA 延迟跟得上 |
| 匀速段 | 越长越好 | — | 加速度=0 时零扰动 |
| 加减速段时长 | **≥ 1 秒** | 0.5 秒 | 渐变过程给前馈时间 |

---

## 五、推荐运动曲线(S 形/梯形速度规划)

```
速度 v
  │          ┌──────────────┐
  │         /                \
  │        /                  \
  │       /                    \
  └──────┴─────────────────────┴────→ 时间 t
       ↑                          ↑
    加速段 ≥1s                减速段 ≥1s
    (0→2 m/s² 渐变)          (2→0 m/s² 渐变)
```

### 分段说明

| 阶段 | 加速度 | 时长 | 球的状态 |
|------|--------|------|---------|
| 加速段 | 0 → 2 m/s² 渐变 | ≥1s | 前馈全程跟随,球微动(<1cm) |
| 匀速段 | 0 | 任意 | 零扰动,球锁定 |
| 减速段 | 2 → 0 m/s² 渐变 | ≥1s | 前馈全程跟随,球微动 |
| 停止 | 0 | — | 球回中锁定 |

### 反例(不要这样)

```
✗ 阶跃加速:  0 → 3 m/s² 瞬间
   → 前馈跟不上,球被甩 3cm+,需要 PID 追

✗ 过猛加速:  峰值 4 m/s²
   → 前馈限幅 12° 只够抵消 2.1,球滑动

✗ 频繁启停:  每 0.5s 一次启停
   → 球一直在晃,永远稳不下来
```

## 六、编码器加速度估计(主控端)

### 数据发送要求

| 项目 | 要求 |
|------|------|
| 帧类型 | TYPE 0x42 (已有) |
| 发送频率 | ≥ 20Hz(50ms 一帧) |
| 左右轮编码器 | 原始脉冲计数 |
| 时间戳 | 上电毫秒数 |

### 加速度计算(主控端)

```
1. 速度:  v = Δ脉冲 × 每脉冲米数 / Δt
2. 加速度: a = Δv / Δt
3. 平滑:  a_filt = 0.5×a_filt + 0.5×a_raw  (和 MSPM0 端一致)
```

### 已知问题

MSPM0 端编码器两次差分噪声较大(±2.4 m/s² 跳变),已用 EMA 滤波压制。
若主控端能做**速度闭环**,直接发"设定加速度"比发"测量加速度"更干净(无差分噪声)。

## 七、如果主控做不到平滑控制

### 退而求其次的方案

| 方案 | 做法 | 效果 |
|------|------|------|
| A. 压低加速度 | 峰值 ≤1 m/s² | 前馈限幅有 2 倍余量,位移小 |
| B. 减少启停 | 一次跑完,避免频繁启停 | 球大部分时间在匀速段(零扰动) |
| C. 提前减速 | 到站前 1m 开始减速 | 减速渐变,球不被甩 |

### 推荐组合

```
主控控制模式: 位置闭环(定速巡航)
  → 加速度自然受限(电机电流/速度环限制)
  → 只需保证: 速度变化平缓 + 峰值加速度 ≤2 m/s²
```

## 八、验证方法

### 路测检查

```
车匀速行驶时: S 显示 ball 应稳定在 ±1cm 内   ✅
车加速段:     ball 位移 ≤2cm                 ✅
车减速段:     ball 位移 ≤2cm                 ✅
车停止后:     球 2~3 秒内回中锁定             ✅
```

### 不达标的信号

```
加速时 ball 位移 >3cm → 加速度太大或太陡 → 减加速度/延长加减速段
```
