# 球平衡视觉PID 调参指南

## 系统概述

```
MaixCam → UART2 → MSPM0 → PID → CL_SetTargetAngle → CL_Process → 步进电机
 20Hz              5ms      200Hz     角度指令          burst伺服     平台倾角
```

- 视觉帧率 ~20Hz，PID 用 `VisionEstimatorUpdate` 做 frame_id 去重 + 低通滤波速度
- PID 使用 `PID_UpdateWithDerivative(error, filtered_velocity, dt)`，D 项直接喂滤波速度，不内部差分
- 输出限幅 ±6°，通过斜坡限幅（80°/s）平滑过渡，再交给 CL_Process 执行

## UART0 命令速查

| 命令 | 功能 | 示例 |
|------|------|------|
| `V` | 启动视觉PID（sp=0cm） | `V` |
| `W` | 停止视觉PID | `W` |
| `N <cm>` | 设目标位置 | `N 0` / `N 5` / `N -3` |
| `J <val>` | 设 KP (deg/cm) | `J 0.8` |
| `M <val>` | 设 KD (deg/(cm/s)) | `M 0.25` |
| `I <val>` | 设 KI | `I 0.05` |
| `S` | 查看状态 | `S` |
| `P` | 查看力学参数 | `P` |
| `A <val>` | 设加速度 (m/s²) | `A 1.5` |
| `T <val>` | 设 trim 微调角 (°) | `T 1.0` |
| `D <val>` | 手动倾角 (°) | `D 3` |
| `X` | 紧急停止 | `X` |

## 参数速查

| 参数 | 默认值 | 含义 | 调大效果 | 调小效果 |
|------|--------|------|----------|----------|
| `VIS_KP` | 0.8 | 位置增益 deg/cm | 响应快、可能振荡 | 响应慢、不振荡 |
| `VIS_KD` | 0.25 | 速度阻尼 deg/(cm/s) | 刹车强、过冲小 | 刹车弱、过冲大 |
| `VIS_KI` | 0.0 | 积分消除稳态误差 | 消除残余偏差 | — |
| `VIS_VELOCITY_FILTER_ALPHA` | 0.70 | 速度低通滤波 | 更平滑、略延迟 | 响应快、噪声大 |
| `VIS_POSITION_DEADBAND_CM` | 0.15 | 位置死区 cm | — | — |
| `VIS_VELOCITY_DEADBAND_CM_S` | 1.0 | 速度死区 cm/s | — | — |
| `VIS_OUTPUT_MAX_DEG` | 6.0 | PID 输出上限 ° | — | — |

> 滤波系数和死区改 `demo_config.h` 需要重新编译，Kp/Kd/Ki 可用串口命令实时调。

## 调参步骤

### 准备

```
1. 硬件上电（12V、USB-C×2）
2. 等待自动归零完成（PWM≈143°，串口打印启动信息）
3. 球放摆杆中间（约 0cm 位置）
4. 确认 MaixCam 工作（红灯常亮，镜头对准摆杆）
```

### 第1步：关D关I，找P临界值

```
M 0          ← KD = 0
I 0          ← KI = 0
V            ← 启动PID
```

从小到大试 KP，每次看 `S` 观察球的行为：

```
J 0.3 → 球慢慢漂走，回不来           ← KP 太小，继续加
J 0.6 → 球能回来，但很慢             ← 还不够
J 0.9 → 球回来了，冲过头弹回去       ← 接近了
J 1.2 → 球来回振荡，幅度不衰减       ← 这就是临界 KP
J 1.5 → 振荡更剧烈                   ← 超标了
```

**记录**：临界 KP ≈ ___，振荡周期 Tu ≈ ___ 秒（看 S 输出 ball 值摆动一次的时间）

### 第2步：回退KP，加KD阻尼

```
J <临界KP × 0.6>     ← 例如 1.2×0.6 ≈ 0.7
M 0.1                 ← 从小 KD 开始
```

观察并调整：

| 现象 | 操作 |
|------|------|
| 球过冲超过目标 | `M +0.1` 加大刹车 |
| 球回来太慢、反应迟钝 | `M -0.05` 减小刹车 |
| 球到中心附近轻微摆动后稳住 | ✅ 这组 Kp/Kd 可用 |

> **经验公式**：KD ≈ KP × Tu × 0.3  
> 若 Tu=0.5s：KD ≈ 1.2 × 0.5 × 0.3 ≈ **0.18**

### 第3步：微调KP+KD组合

```
以第2步的值为起点，交替微调：
```

| 球的行为 | 问题 | 操作 |
|----------|------|------|
| 小幅持续摆动（高频） | KD 不够 | `M +0.05` |
| 大幅缓慢摆动（低频） | KP 太大 | `J -0.2` |
| 球偏一边回不到0cm | KP 不够 | `J +0.1` |
| 球反应迟钝、像在泥里 | KP+KD都大 | `J -0.2` `M -0.05` |

**目标：球放中间松手后，2-3 秒内稳定在 ±3mm 以内。**

### 第4步：加积分（如需要）

如果 PD 调好后球停在离 0cm 差 0.3cm 以上的位置（稳态误差）：

```
I 0.02       ← 先加很小
```

等 5-10 秒观察：

| 现象 | 操作 |
|------|------|
| 误差慢慢缩小，球到 0cm | ✅ KI 合适 |
| 缩小太慢 | `I 0.05` |
| 出现小幅振荡 | KI 太大，`I 0` 放弃积分 |

> **能不用就不用**。PD 调好通常不需要 KI。

### 第5步：跨位置验证

```
N 5          ← 目标移到 +5cm，观察球移动过程
N 0          ← 回到中心
N -3         ← 测试负方向
```

| 现象 | 操作 |
|------|------|
| 过冲超过目标 0.5cm | `M +0.1` 加大阻尼 |
| 到不了目标（差 >0.3cm） | `J +0.2` 或 `I 0.03` |
| 来回振荡几次才稳 | `M +0.05` |
| 三个位置都顺利到位 | ✅ 调参完成 |

## 典型问题排查

### 球完全不动 / 电机不转

```
S  ← 检查
```

- PWM≈143 且 act=0？→ 归零没完成，等
- valid=0？→ MaixCam 没发数据，检查 UART2 接线和 MaixCam 供电
- ball 值始终不变？→ 检查摄像头是否对准、光照是否充足

### 球一启动就飞出去

```
X  ← 立刻急停
```

- KP 太大 → `J 0.3` 重新开始
- 方向反了 → 检查 `AXIS_X_POSITIVE_DIR_LEVEL` 是否和实际一致
- 速度滤波太小导致噪声放大 → 改 `VIS_VELOCITY_FILTER_ALPHA = 0.85`

### 球在目标附近高频抖动

- KD 不够（阻尼不足）→ `M +0.1`
- 或者视觉噪声大 → 改 `VIS_VELOCITY_FILTER_ALPHA = 0.85`，增大 `VIS_POSITION_DEADBAND_CM = 0.2`

### 球稳定但位置有偏差

- 平台物理不平 → `T 0.5` 或 `T -0.5` 调 trim
- 有稳态误差 → `I 0.03`

## 推荐参数组合

### 保守（稳但慢）
```
J 0.5    M 0.2    I 0
```
适合初次调试，不容易飞。

### 均衡（推荐）
```
J 0.8    M 0.25   I 0
```
速度和稳定性兼顾。

### 激进（快但可能振荡）
```
J 1.2    M 0.35   I 0.02
```
需要系统已经调得比较好才能用。

## 快捷操作流程

```
上电 → 等归零 → 球放中间
V                 ← 启动
S                 ← 看球位置
J 0.3             ← 从小 KP 开始
M 0               ← 关 D
... 按步骤调到球稳 ...
N 5 → N 0 → N -3  ← 验证三个位置
完成！
```

**记住核心三句话：KP 管力度，KD 管刹车，KI 管精准。先 KP+KD 调到稳，够用就不加 KI。**
