2. 上电启动流程

2.1 main() 启动序列

1
硬件 SYSCFG_DL_init() — 系统时钟 + GPIO 初始化
SysConfig 生成的代码：配置 80MHz 主频、所有引脚复用、UART/TIMER 外设时钟。这是上电后执行的第一条语句。
2
硬件 Board_LED_Init() — 板载 LED 亮起
PB22 推挽输出，点亮 LED 表示 MCU 已启动。如果 LED 不亮：检查供电、复位电路。
3
硬件 Motor_Init() — 电机驱动器初始化
EN 引脚拉高 → 锁轴（电机上电即锁定，防止自由转动）
DIR 引脚拉低 → 默认方向
STEP 引脚低电平
配置 TIMA1 硬件 PWM 用于 STEP 脉冲生成，使能中断
4
硬件 Encoder_Init() — 编码器初始化
TIMG8 QEI 模式：A/B 正交解码 (4000 counts/rev)
TIMG12 捕获模式：PWM 绝对角度测量 (MT6816 协议)
Z 索引中断使能 (PA25)
5
硬件 UART 中断使能
UART2 (视觉) RX 中断 — 接收 MaixCam 球位置数据
UART1 (主控) RX 中断 — 接收主控 AA55 命令
6
应用 Demo_Init() — 应用层初始化
执行顺序：
  1. ProtoRx_Init() — 视觉数据协议解析器复位
  2. TaskCtrl_Init() — 赛题状态机复位，UART1 中断使能
  3. CL_Init() — 闭环控制器复位，编码器零点归零
  4. (DEMO5/7/8) BallControl_Init() — 回零状态机进入 HC_INIT
  5. (DEMO7/8) MechBalance_Init() — 力学参数/视觉PID初始化
  6. 打印启动横幅 (模式号、细分、串口信息)
7
硬件 TIMER 中断使能
TIMG0 配置为 5ms 周期中断 → 进入主循环前最后一步
使能后立即开始 5ms 定时调度
8
应用 while(1) Demo_Process() — 主循环
轮询 UART0 调试串口 → 解析串口命令
各 Demo 模式的具体逻辑在主循环中执行

2.2 5ms 中断调度 (TIMER_0_INST_IRQHandler)

每 5ms 触发一次，是系统的"心跳"，执行顺序固定：

DEMO 模式调度顺序
DEMO 5
(平衡球)		 Encoder_Tick(5) → 读取 QEI 增量、更新 PWM 超时
ProtoRx_Tick(5) → 视觉数据超时计数
TaskCtrl_Tick5ms() → 赛题状态机、轨迹、超时检测
BallControl_Tick5ms() → 回零 + 球 PID 闭环
CL_Process() ×4 → 电机闭环步进（4 次加速收敛）
DEMO 8
(视觉PID)		 Encoder_Tick(5)
ProtoRx_Tick(5)
BallControl_Tick5ms() → 回零状态机
MechBalance_Tick5ms() → 视觉PID / 力学前馈 / 手动倾角
CL_Process() ×1 → 仅回零期间执行；回零完成后不执行
DEMO 7
(纯力学)		 BallControl_Tick5ms()
MechBalance_Tick5ms() → 力学前馈 / 手动倾角
CL_Process() ×4
DEMO 3/4 CL_Process() ×1
⚠️ 注意：DEMO8 在回零期间 CL_Process 只执行 1 次/5ms（电机慢速转动）； 回零完成后 CL_Process 不再被调用，电机目标角度通过 CL_SetTargetAngle() 直接设置， 闭环控制器在 CL_SetTargetAngle 内部立即启动步进。

2.3 DEMO8 完整启动时间线

时间阶段状态关键事件
0 ms上电硬件初始化 SYSCFG → LED 亮 → Motor EN 拉高锁轴 → Encoder 启动
~10 ms应用初始化Demo_Init() 协议解析器/状态机/闭环/PID/回零状态机 全部就绪
~15 ms进入主循环等待 PWM 5ms 中断开始运行，回零状态机进入 HC_WAIT
0–3 s等待 PWM 信号HC_WAIT 等待 MT6816 输出稳定的 PWM 绝对角度
超时 3s → HC_FAULT
3–18 s回零运动HC_SEEK 电机以 100Hz 连续转动，实时读取 PWM 角度
当 PWM ∈ [PWM_HORIZONTAL_REF ± TOL] → HC_READY
超时 15s 或 1.5s 无进展 → HC_FAULT
~完成回零完成HC_READY 电机停止，编码器零点设为当前位置
串口打印横幅，等待用户/主控指令

4.2 DEMO8 控制模式优先级

在 5ms 中断中，MechBalance_Tick5ms() 按以下优先级选择输出：

  1. 紧急停止 — 串口 X 触发，永久锁死，需重启
  2. 视觉 PID — 串口 V 启动 / W 停止
    球丢失 → 保持当前角度不退出；PWM越界 → 钳位不退出；仅X/断电可退出
  3. 手动倾角 — 串口 D <角度> 设定
  4. 力学前馈 — 默认模式，根据加速度计算倾角补偿
    θ = atan2(-gain·ax, g) × 57.3° - pitch + trim

7. 调参流程（推荐步骤）

7.1 赛前准备

  1. 确认接线：对照 empty.c 头部接线表检查所有连接
  2. 确认 D36A 拨码：MS1/2/3=OFF(16细分)，与 D36A_MICROSTEP=16 一致
  3. 确认编码器方向：
    • 烧录 DEMO 2 → 串口发 1 让电机正转
    • 观察编码器读数是否递增 → 若递减则改 ENCODER_AXIS_X_SIGN = -1
  4. 确认电机方向：
    • 烧录 DEMO 2 → 串口发 1 看电机旋转方向
    • 若正转方向反了 → 改 AXIS_X_POSITIVE_DIR_LEVEL = 0（或 1→0）
  5. 标定水平 PWM：
    • 手动将摆杆调至水平
    • 烧录 DEMO 2 → 串口发 2 启动连续转动 → 读取 PWM 值
    • 将稳定值填入 PWM_HORIZONTAL_REF
  6. 标定机械限位：
    • 手动将摆杆推到正向极限 → 记录 PWM 值 → 填入 PWM_LIMIT_HIGH
    • 手动将摆杆推到反向极限 → 记录 PWM 值 → 填入 PWM_LIMIT_LOW

7.2 视觉 PID 调参 (DEMO8)

调参原则：先 KP 后 KD，KI 通常置 0。运行中通过串口 J/M/I 命令实时修改， 观察 S 命令输出判断效果。调好后将最终值写入 demo_config.h 重新编译。

第一步：调 KP (比例增益)

  1. 上电等待回零完成 → 串口发 V 启动视觉 PID
  2. 发 N 0 设目标位置 0cm
  3. 将球放在 +3cm 处，观察它是否回到 0cm
    • 球回得太慢 → 增大 KP（如 J 1.2）
    • 球冲过 0cm 振荡 → 减小 KP（如 J 0.5）
  4. 反复调整直到球能从 ±3cm 快速回到 0cm 附近且不过冲太多

第二步：调 KD (微分增益 — 阻尼)

  1. KP 确定后，球可能在 0cm 附近来回振荡
  2. 增大 KD 抑制振荡（如 M 0.4）
    • KD 太小 → 振荡不衰减
    • KD 太大 → 球响应变慢、迟钝
  3. 目标：球快速回到 0cm 且无明显过冲振荡

第三步：调 KI (积分增益 — 消除静差，可选)

  1. 如果球稳定后始终偏离目标 0.2–0.5cm，可加小 KI
  2. 从很小值开始：I 0.01，观察是否改善
  3. KI 过大 → 低频振荡，不易收敛

第四步：速度滤波调优

  1. VIS_VELOCITY_FILTER_ALPHA（需重新编译）：
    • 视觉数据噪声大 → 增大 ALPHA（如 0.85），速度更平滑
    • 响应太迟钝 → 减小 ALPHA（如 0.5），速度跟随更快
  2. VIS_POSITION_DEADBAND_CM：球进入 ±0.15cm 内暂停 PID，避免微振
  3. VIS_VELOCITY_DEADBAND_CM_S：球速度 <1cm/s 时也暂停 PID

7.3 力学前馈调参 (DEMO7 预调)

力学前馈是视觉 PID 的"基础层"。在没有视觉数据的 DEMO7 模式下调试：

  1. 上电回零完成 → 串口发 A 1.0 模拟 1m/s² 加速度
  2. 观察电机倾角响应：
    • 发 S 查看当前角度
    • 如果需要更大倾角 → 增大 G（前进增益）
    • 刹车时倾角不够 → 增大 B（刹车增益）
  3. 摆杆机械零偏：发 T 0.5 微调 trim
  4. 角度变化速率：发 L 60 限制为 60°/s（保护电机）
