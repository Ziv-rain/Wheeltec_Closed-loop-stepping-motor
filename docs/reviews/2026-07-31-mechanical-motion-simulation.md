## 发现的问题及优先级

### P1：当前固件已取消机械角限幅

源提交把直接角度和序列角度的限幅删除，串口 Q/D 命令可以给出任意角度。
本任务给定的安全范围是向上 `+45°`、向下 `-30°`。仿真器始终按此范围截断
命令角和电机实际角；实机固件仍应恢复独立的硬限幅和越界故障处理。

### P1：现有四段序列不能表达完整的两个标定点任务

当前 `mech_balance.c` 只有四个角度/时长槽位，适合一次“驱动—制动—回零”，
不能完整表示 `0 -> +5 -> -5` 两个航段的独立加速、制动和静置过程。
本次生成六段参考轨迹，暂不直接替换固件状态机，避免未经台架验证就改变电机行为。

### P1：开环角度序列没有物理参数辨识

现有默认角度和时长不是根据球半径、滚动阻力、机构传动比和电机响应拟合得到的，
因此无法从代码判断能否到达标定点。新增模型和确定性拟合器，用于生成首轮实验参数。

### P2：开环过程对实物变化敏感

灰尘、梁的局部变形、水平零点、初始速度及钢球差异都会改变结果。仿真只能提供
台架起点，最终应依赖视觉位置和速度进行到点修正。

## 实际修改

- 新增 `tools/mechanical_motion_sim.py`：
  - 实心球无滑动滚动模型，重力项系数为 `5/7`；
  - 库仑滚动阻力和粘性阻尼；
  - 电机最大角速度、一阶响应、传动比及角度边界；
  - 对两个航段分别自动拟合“驱动—制动—静置”；
  - 可通过命令行调整全部关键参数和目标点；
  - 输出 CSV、SVG 和 C 参考轨迹表。
- 新增 `tests/test_mechanical_motion_sim.py`，检查到点误差、残余速度、角度边界和
  拟合可重复性。
- 新增 `docs/mechanical-motion-simulation.md`，记录运行方法、参数含义和上机步骤。
- 提交默认拟合结果至 `simulation/`。

## 默认模型与拟合结果

默认假设：

- 滚动阻力系数：`0.012`
- 粘性阻尼：`0.55 1/s`
- 电机角与梁角传动比：`1.0`
- 电机最大角速度：`100 deg/s`
- 电机一阶响应时间：`0.06 s`
- 仿真步长：`5 ms`
- 角度边界：`[-30°, +45°]`

拟合的六段指令：

| 航段 | 动作 | 角度 | 持续时间 |
| --- | --- | ---: | ---: |
| 0 → +5 cm | 驱动 | +7.4677° | 223 ms |
| 0 → +5 cm | 制动 | -2.2530° | 347 ms |
| 0 → +5 cm | 静置 | 0° | 302 ms |
| +5 → -5 cm | 驱动 | -3.6960° | 696 ms |
| +5 → -5 cm | 制动 | +2.9993° | 370 ms |
| +5 → -5 cm | 静置 | 0° | 521 ms |

总时间约 `2.455 s`。默认仿真得到：

- 标定点 2：`+5.000 cm`，残余速度约 `0 cm/s`；
- 标定点 1：`-4.998 cm`（重新按毫秒表执行约 `-5.000 cm`），残余速度约 `0 cm/s`；
- 轨迹范围约 `[-5.000 cm, +5.000 cm]`；
- 指令角范围 `[-3.6960°, +7.4677°]`，未接近给定极限。

## 未解决风险

- 尚未使用实测数据辨识摩擦、阻尼、电机响应和机构传动比；
- 未建模钢球打滑、碰撞、梁挠曲、电机回差和角度传感器噪声；
- 轨迹表尚未接入固件状态机，接入时需要停止/急停、看门狗及角度越界保护；
- 当前源分支取消了固件角度限幅，实机运行前必须另行修复；
- 纯开环不能保证不同台架上重复到点，建议比赛版本增加视觉闭环。

## 烧录与部署注意事项

本分支是 PC 仿真和参考轨迹，不是已验证的烧录发布版本；仓库配置未指定
`releaseBranch`，不得把本分支直接作为正式烧录分支。上机前应先确认电机正负方向，
在无球或有限位保护的条件下逐段低速执行，再根据视觉日志重新拟合参数。
