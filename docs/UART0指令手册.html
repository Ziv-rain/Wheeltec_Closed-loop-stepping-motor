1. 基础说明

项目值
串口UART0
引脚PA28(TX) / PA31(RX)
波特率115200-8-N-1
发送格式ASCII 文本 + 回车(\r\n)
自动输出每 500ms 打印一行 S 状态
⚠️ 重要: UART0 是调试口(115200)。UART1 才是主控口(9600, AA55 帧)。别搞混!
命令格式: 字母 + 空格 + 数值 + 回车。例如 J 2.5 回车。
超范围的参数被静默拒绝(无提示),用 P 确认实际值。

2. 赛题控制

命令功能等同 UART1
# <N>选择赛题 N (2~6)0x40 01 N
V开始(有选中赛题→自动回零+PID启动)0x40 02
W停止(停状态机+PID)0x40 03
!停止赛题0x40 03
@启动第 3 题(一键)0x40 02 (T3)

赛题流程

# 5    ← 选T5 (OK Task=5)
V      ← 开始 (电机先回水平零点 → PID启动 → 球控制)
W      ← 停止

# 6    ← 选T6 (OK Task=6)
V      ← 开始
(球稳定±1cm达500ms → 自动DONE)
V 的智能行为: 选了赛题走完整状态机(自动回零);没选赛题直接启动 PID(纯调试)。

3. 球控制 PID 参数

命令参数范围默认说明
J <值>KP0.2 ~ 8.02.35位置增益, 响应快慢主旋钮
M <值>KD≥0 无上限0.50速度阻尼
I <值>KI0 ~ 0.080.02积分(条件启用)
O <值>输出下限-10 ~ -1-6PID 输出范围
U <值>输出上限1 ~ 106PID 输出范围
T <值>trim±4°0静态零偏补偿(水管不平)
N <值>目标位置±9cm0setpoint

调参口诀

响应慢   → J 加大
振荡     → M 加大 (或 J 减小)
球偏一边 → T 补偿 (偏正侧→T负, 偏负侧→T正)
静差     → I 0.04 试

4. 前馈参数

命令参数范围默认说明
G <值>前进增益≥0 无上限9.2加速度→倾角斜率(正加速)
B <值>刹车增益≥0 无上限2.0加速度→倾角斜率(负加速)
E <值>前馈限幅4 ~ 30°8前馈角度上限
F <0/1>融合开关0/11前馈是否叠加到PID
A <值>手动加速度±30模拟加速度(测试前馈)

前馈测试流程(不用启动车)

F 1     ← 开融合
V       ← 启动
A 1     ← 模拟加速 1 m/s²
S       ← 看 ff 应为负(推球向前抵消惯性)
A 0     ← 复位
G/B/E 调参逻辑: ff 未打满调 G/B(斜率);ff 打满调 E(上限)。S 的 ff 字段判断。

5. 第 3 题参数

命令功能默认
H <值>设 tgt1 (初始目标 cm)4.0
K <值>设 tgt2 (终值 cm)-5.0
Y <值>设 mid (摆荡中间目标 cm)1.5
Q <值>设 ramp 时长 (ms)750
C <值>设 tol (到位容差 cm)0.8
@一键启动 T3-

T3 轨迹

tgt1(4.0) → 球过4.5cm → mid(1.5) → ramp → tgt2(-5.0)
→ 球过-4.5cm → 刹车(2.5°) → 500ms → DONE

6. 其他命令

命令功能
S查看状态(每500ms也自动输出)
P查看参数列表
D <角度>直接设电机角度(±30~45°)
L / R <值>设角度变化率(10~80°/s)
Z置零(提示归自动回零管)
X紧急停止(锁死需重启)

7. 典型调试流程

流程 1:调球控制

F 0     ← 关前馈
V       ← 启动PID
J 2.5   ← 调KP
S       ← 看球是否回中
M 0.6   ← 振荡就加阻尼

流程 2:调前馈(不启动车)

F 1     ← 开融合
V       ← 启动
A 1     ← 模拟加速
S       ← 看ff方向/大小
G 9.2   ← 调前进增益
E 8     ← 调限幅
A 0     ← 复位

流程 3:跑赛题

# 5     ← 选T5
V       ← 开始(自动回零+PID)
S       ← 观察
W       ← 停止

8. S 输出解读

Tgt=4.41 Act=4.23 PWM=138.35 | VIS: act=1 valid=1 sp=0.00 ball=5.48 vel=0.00 out=4.38 KP=2.35 KD=0.50 omin=-6.0 omax=6.0 ff=0.00 ax=0.00 merged=1
 │         │         │              │         │        │        │       │       │                     │       │         ↑
 目标角    实际角    PWM绝对角       是否启动   视觉有效  目标位置  球位置  球速度  PID输出              前馈角  加速度    融合开关
字段含义诊断
act是否启动0=待机 1=运行
valid视觉有效0=丢失
ball球位置 cm应接近 sp
vel球速度 cm/s稳定≈0
outPID输出 °卡住=out不够
ff前馈角 °ax≠0时跟随; 恒0=数据没来
ax加速度 m/s²车不动应0
merged融合激活1=前馈+PID
