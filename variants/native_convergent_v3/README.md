# Ball-and-Beam 原车参数约束版 V3

## 结论先说

这一版是给当前天猛星 MSPM0G3507、MS42CG 编码器步进电机、D36A、
MaixCAM 20 Hz 视觉链路单独写的控制版本。它没有移植参考开源项目的
电机协议、像素坐标、70°水平角、ZDT 参数或 PID 数值，也没有修改本仓库
现有 `Control/`、`Hardware/`、`empty.c` 和 CCS 配置。

V3 只替换视觉平衡算法模块，继续使用当前成熟链路：

```text
MaixCAM 原代码
  AA 55 / TYPE 0x30 / LEN 8 / CRC16
        ↓
原 Hardware/proto_rx.c
        ↓
V3 新帧控制器（视觉约 20 Hz）
        ↓
原 CL_SetTargetAngle / CL_Process（5 ms）
        ↓
原 D36A STEP/DIR + MS42CG A/B/PWM 反馈
```

核心目标是解决当前约 `+8 cm ↔ -8 cm` 大幅往返、不衰减，以及小角度时
克服不了静摩擦的问题。处理方法不是继续把全局 Kp 拉高，而是把“滚动时
收敛”和“静止时脱困”分开。

## 对参考文档的分析结论

从《上车后平衡球开源代码逻辑详解》中只吸收以下结构思想：

- 视觉直测、视觉保持、滚动、脱困、稳定分别处理；
- 静摩擦推球和运动中的速度制动不能共用一个大增益；
- PID 只使用新的直接视觉测量，不能对缓存帧重复积分；
- 远离目标和接近目标使用不同的制动强度；
- 视觉丢失、机械限位、急停的优先级高于普通控制；
- 输出必须经过统一角度限幅和变化率限制；
- 调参必须保留原始数据、状态和版本，不能只看“最后球停在哪里”。

以下内容明确没有移植：

| 参考项目内容 | 不采用原因 | V3 使用的本车数据 |
|---|---|---|
| `70°` 水平角 | 参考项目是 ZDT 正绝对角机构 | 本车回零后相对角 `0°`，PWM 水平实测 `135.21°` |
| `20°～100°` ZDT 范围 | 电机与机械结构不同 | 原车 PWM `105°～190°`，相对机械角 `-30°～+45°` |
| `10.41/0.0025/0.5` 像素 PID | 单位是 px，方向和执行器不同 | 本车单位 cm、deg/cm、deg/(cm/s) |
| `18°～26°` 脱困 | 对本车过于激进 | 本车实测约 `+3°/-5°`，V3 只留 `0.2°` 余量 |
| `/dev/...` ZDT 串口帧 | 本车电机不用该协议 | 原 `CL_*`、D36A STEP/DIR、编码器反馈完全保留 |
| `260 px/s²` 制动模型 | 没有本车辨识依据 | 使用本车 20 Hz 延迟预测和速度反馈，不写死他车减速度 |

### V3 的保守控制初值

| 参数 | V3 初值 | 本仓库依据 |
|---|---:|---|
| 滚动 Kp | `0.80 deg/cm` | 原调参指南“均衡值”和原回程审阅值 |
| 速度 Kd | `0.50 deg/(cm/s)` | 当前 `origin/main` 实际值 |
| 条件 Ki | `0.02` | 当前 `origin/main` 实际值 |
| 积分状态限幅 | `±3` | 当前 `origin/main` 实际值 |
| 动态修正限幅 | `±6°` | 原回程审阅中的保守精调边界 |
| 正向脱困 | `+3.2°` | 本车实测 `+3°` 可推回，再留 `0.2°` |
| 负向脱困 | `-5.2°` | 本车实测 `-5°` 可推回，再留 `0.2°` |
| 脱困确认 | `0.30 s` | 原视觉帧与静止判断量级 |
| 脱困释放 | 位移 `0.10 cm`、速度 `0.25 cm/s` 或 `0.20 s` | 球一动即卸载，防止持续大角度注入能量 |
| 速度滤波 | 3 个新帧，旧值权重 `0.50` | 原回程分支的低延迟速度设置 |
| 预测时间 | `0.10 s`，最多预测 `1 cm` | 原 `0.20 s` guard 的保守一半，覆盖 20 Hz 与处理延迟 |
| D 远距比例 | `35%` | 远处保留部分阻尼，近 `1 cm` 逐步全开 |
| 位置死区 | `0.20 cm` | 原回程分支值 |
| 稳定判定 | `±0.30 cm`、`≤0.60 cm/s`、连续 `0.50 s` | 比题目 `±0.5 cm` 留出余量 |
| 稳定退出 | `0.60 cm` 或 `1.20 cm/s` | 增加滞回，避免视觉噪声反复切换 |
| 丢失回水平速率 | `20°/s` | 小于原正常 `80°/s`，避免突然回零 |
| 恢复确认 | 连续 2 个直接帧 | 避免刚找回一帧就重新推球 |

这里没有在线自动改 Kp/Kd。现场数据不足时自动改增益风险很高；V3 只做
确定性状态切换和有界补偿，所有基础参数都可追溯。

## 为什么当前 200 Hz PID 会放大振荡

当前 `origin/main` 的视觉发送端约每 50 ms给一个新位置，但
`Control/mech_balance.c` 每 5 ms对同一位置、同一速度执行一次
`PID_UpdateWithDerivative(..., 0.005)`：

- 同一帧被重复计算约 10 次；
- Ki 的有效累积速度由 MCU tick 决定，不再由真实测量周期决定；
- 上一帧速度被连续当成 10 次“新速度”施加；
- 相机端已经有 `ALPHA=0.35` EMA 和 `dual_buff=True`，再叠加 MCU 速度低通，
  实际制动相位进一步落后；
- `Kp=3.0`、输出 `±10°` 在误差超过约 `3.3 cm` 后长期饱和，容易把
  Ball-and-Beam 变成正负最大角度的继电振荡。

V3 的两个时钟职责严格分开：

- 新视觉帧：更新位置、真实帧间速度、预测、P/I/D、状态机；
- 每 5 ms：只做视觉超时、安全检查、角度斜率和原电机位置闭环。

## V/W/X 的明确语义

- 上电回零后保持水平，不自动进入 PID；
- 发送一次 `V`，锁存 `requested=1`；
- 普通视觉丢失、低置信度、短时 PWM 反馈缺失不会清除这个请求；
- 视觉丢失时以 `20°/s` 回到水平/前馈基准；连续两个直接帧恢复后自动继续；
- 只有 `W` 明确暂停 PID；
- `X` 是独立锁存急停，停止电机输出且必须重新上电恢复；
- PWM 真正越过硬范围或原 `CL_*` 报故障也会进入安全锁存，绝不为了
  “V 永久在线”绕过机械保护。

因此，“PID 请求不退出”和“故障时仍强行驱动”被明确分开。

## CCS 中作为独立版本运行

不要删除或覆盖原 `Control/mech_balance.c`。在 CCS 中复制当前 Debug 配置，
命名为例如 `native-convergent-v3`，只对该新配置执行：

1. 将原 `Control/mech_balance.c` 设为 **Exclude from Build**；
2. 把以下两个文件加入该配置：
   - `variants/native_convergent_v3/mspm0/native_v3_core.c`
   - `variants/native_convergent_v3/mspm0/mech_balance_v3.c`
3. 给编译器增加 include 路径：
   - `${PROJECT_ROOT}/variants/native_convergent_v3/mspm0`
   - 保留现有 `${PROJECT_ROOT}/Control`、`${PROJECT_ROOT}/Hardware`；
4. 其余源文件保持当前 `origin/main@fb1972d` 不变；
5. 重新运行 SysConfig，执行完整 Debug 构建。

`mech_balance_v3.c` 实现了原 `mech_balance.h` 的全部函数，因此当前
`Control/app_demo.c`、UART0 命令和 `empty.c` 不需要改动。

## 第一次实机顺序

1. 无球上电，确认自动回零后 `PWM≈135.21°`，相对角约 `0°`；
2. 不发 `V`，遮挡相机并确认摆杆保持水平；
3. 使用小角度 `D1`、`D-1` 再次确认“正角让球向负位置走”；
4. 放球在 `+2～+3 cm`，执行 `N0`、`V`；
5. 连续执行 `S`，确认 `valid=1`、速度符号正确、输出不超过 `±6°`；
6. 遮挡相机，确认 `act=1` 仍表示请求锁存，但 `valid=0` 且角度缓慢回水平；
7. 恢复相机，确认两帧后自动继续；
8. 先做 `+3→0`、`-3→0`，再做 `+5→-5`，最后才做 `±8 cm`；
9. 全程准备 `X` 和物理断电。

## 只允许的小步调参

默认先不改。若必须调整，每次只改一项并保存 `S` 的连续日志：

- 仍在目标两侧低频大幅摆动：`M0.55`，最多先到 `0.60`；
- 明显提前刹住但离目标仍在移动方向一侧：`M0.45`；
- 球滚动后整体太慢：`J0.90`，不要直接回到 `J3.0`；
- 目标附近静差小于 `0.5 cm`：先调 `T±0.1～0.2°`，不要先加 Ki；
- 正方向静止仍推不动：先检查水平和摩擦，脱困角最多按 `0.2°` 级调整；
- 任何调整后都重新测试正负两个方向，不能只看单边。

禁止第一轮就把输出恢复到 `±10°`，也禁止同时提高 Kp、Kd 和脱困角。

## 仿真边界

仿真覆盖 `+8→0`、`-8→0` 和 `+5→-5`，视觉延迟
`50/100/150 ms`，未知角度到加速度增益 `1.2/2.4/3.0`，并包含：

- 原 MaixCAM `0.35` EMA；
- 20 Hz 量化位置；
- 正向约 `3°`、负向约 `5°` 的静摩擦；
- 电机角度斜率与机械速度阻尼。

该模型用于排除明显发散参数，不代表真机验收。最终必须以实际日志中的
位置、速度、输出、PWM 和电机反馈为准。
